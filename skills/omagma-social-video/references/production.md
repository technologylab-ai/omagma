# Existing production tools

Read the chosen film's README and current tool help/source before running it. The v0.2.18 source at `video/short0218/` supplies the established production pattern, not a permanent version, duration, capture revision or source hash for future films. Approval belongs to an exact delivered artifact recorded in history; the latest mutable source or export is not automatically approved.

- `capture.py`: genuine compose, booking, Meet, Drive and Calendar takes from a verified published executable. Providers and messages are fictional; receipts assert exact outcomes and write counts.
- `capture-clarity.py`: clean current-time-line and populated Sent takes. It validates actual OS time, earlier/later events, blank red-underlined cells and delivered message identity/recipients/file URL. Its read-only provider Sent list warms genuine cached metadata; it does not prove automatic TUI Sent-cache refresh. Do not reuse its tomorrow-booking assumption on a later date without reseeding a consistent story.
- `capture_terminal.py`, `term.js`, `test_term.mjs`: native terminal replay and fidelity regressions. Keep foreground and SGR58 underline color independent. Chrome can omit all-space underlines; the adapter reproduces those captured cells using font underline metrics. Inspect red pixels rather than trusting attributes. Keep backgrounds behind overhanging glyphs and recorded frame geometry consistent.
- `capture-images.mjs`: rasterizes exact completed native frames and the application's unchanged sandboxed HTML preview. Both top-level and sandboxed child backing surfaces need the intended device scale; a parent-only override can blur child text. Verify the actual embedded image and paragraph order, not just outer HTML.
- `bind-assets.py`: measures camera and spotlight regions from actual cells/DOM. Use actual scrolled review frames for content that does not exist in the unscrolled bitmap. Bound spotlight text to meaningful characters, excluding trailing blank columns beyond the camera. Deduplicate series aliases by actual tape/frame so the same frame is not presented as another countdown/progress tick.
- `resource_guard.py`: verifies the coordinator's live HOST_TOKEN, applies bounded resources and cleans up only owned descendants. Read `docs/VERIFICATION.md#cooperative-host-measurement-lock`; hold the host-local reservation through child cleanup. Use fresh output/report names.
- `cdp.mjs`, `render.mjs`: isolated local headless rendering, one active page. Deterministic source render times, source/manifest hashes and explicit frame ranges support focused previews. Match the driver clock to the actual Opus plan; do not inherit a previous film's frame count accidentally.
- `attention-check.mjs`: independently measures actual DOM visibility and commentary state across every film frame. Its frame count and plan assumptions need review for a new film. Preserve assertions for settled reading time, fixed narration, opacity/clip/transform state and no native UI during announcement phases.
- `encode.py`: full-resolution H.264/BT.709 export with approved AAC copied exactly, complete decoded-frame checks and audio packet/timestamp proof. Adapt its explicit frame count and audio source only to the chosen approved plan.
- `review.mjs`, `review-player.html`: actual encoded playback at1x, wall/media-clock comparison and decoded-frame observations. Match duration/count thresholds to the frozen film. Muted playback is a motion check, not a listening claim.

Run media tools through the resource guard using the coordinator's existing token. Independent reads may run together; keep raster/capture/render/encode/playback stages sequential when they share a bounded host or browser. Do not rebuild the application, run release qualification, overwrite an installed executable or publish a release for a film-only revision.

For a new capture or composite, preserve original tapes and raster images, retain image/tape hashes, record the source attempt and bind exact frames. A declared fallback must itself be genuine, well framed and validated; fail clearly rather than silently returning to an empty screen. Reuse unchanged assets without falsely labeling old capture evidence as a fresh run.

Useful historical source references: `video/short027/` for the approved continuous-film soundtrack and preserved musical edits; `video/short0210/` for the preceding social-film baseline; `video/short0218/` for the approved announce/read/demo style, clear now line and populated Sent ending. Inspect actual approval/history before choosing among preserved cuts. Generated media, private production notes and local receipts are intentionally not public source assets.
