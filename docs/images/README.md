# Public screenshots

The Calendar screenshots below show the released **Omagma v0.2.10 native TUI**
with fictional accounts and fixtures. They contain real application output,
including its theme colours, controls and video-camera glyph.

| Image | View |
| --- | --- |
| [Combined Calendar Week](omagma-calendar-week.png) | Selected calendars across three accounts, with source colours and overlapping events. |
| [New meeting review](omagma-calendar-review.png) | Two guests selected from Contacts and Google Meet generation requested, before confirmation. |
| [Meeting reminder](omagma-meeting-reminder.png) | Automatic countdown with Join, shown over Mail. |
| [Invitation in Mail](omagma-mail-invitation.png) | A native invitation card in the reader, with the Mail sidebar in view. |

Google creates a Meet URL after the event is saved. The review image does not
claim an invitation has already been sent or a link has already been generated.
The screenshots send no mail, write no Calendar events and open no live accounts.

See the [reproduction recipe](../../scripts/public-captures/README.md) and the
[production truth and privacy rules](../../video/PRODUCTION-NOTES.md). Raw PTY
tapes, fixture state, temporary profiles and receipts remain gitignored.

composition of the approved logo, product copy and genuine combined Week
capture. It is rendered from [the social template](../../website/templates/social.html).
