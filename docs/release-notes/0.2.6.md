# Omagma 0.2.6

Bug fixes and quality-of-life improvements for the experimental TUI and agent CLI:

- **Markdown mail.** Compose, reply, reply-all and forward with a live outgoing
  preview; send rendered HTML plus a plain-text alternative. Lists, tables,
  links, inline code and highlighted Python/Zig code fences are supported.
  The small footer puts the logo first, an orange underlined **omagma** link
  next to grey “Sent with”, and 🌋 last. Existing drafts retain their format;
  Ctrl+T changes interpretation without rewriting source.
- **Native attachment picker.** Browse local files, show hidden entries and
  reach controls with Tab/Shift+Tab and Enter. Ctrl+F completes filenames
  case-insensitively while preserving their real spelling. Compose supports
  multiple files; received attachments can be saved or explicitly saved/opened.
  Sizes use readable B/kB/MB units, and existing quota/overwrite protections stay.
- **Reliable forwarding.** Cached Gmail attachment references may change.
  Download the selected reference directly, safely resolve an expired reference
  and normalize padded binary data; preserve files and refuse ambiguous matches.
- **Write above the quote.** New reply and forward bodies start at the top.
  Ctrl+G jumps to the beginning of the body. The native cursor no longer inserts
  a visual blank cell or reflows text while moving.
- **Invitation replies and cleaner text.** Recognize valid iCalendar requests
  in named `.ics` files and common MIME types, including Teams/Outlook mail;
  review Accept, Tentative or Decline before sending an RSVP. Improve encoded
  header/entity and legacy-character decoding for readable text and umlauts.
- **Clearer controls and errors.** Use Ctrl consistently for modified shortcuts,
  leaving Ctrl+B to terminal multiplexers. Forward appears in mailbox/reader
  hints; `o` opens mail in the configured Gmail profile. Error codes appear in
  status and at the top of Help. Unknown commands/options suggest `--help`,
  and `omagma version` works alongside `--version`.

Live cache updates, auto-hiding per-account new-mail cards, `gg` across the cache,
shortened coloured links, HTML-only reading and local dates remain available,
along with `$EDITOR`, cached-correspondent completion, sender identities,
contacts, existing labels, bulk actions/undo and saved working context.

The TUI and CLI remain **experimental** on Linux and macOS. The Omarchy bar stays
Linux-only and read-only. Existing configuration, Chrome profiles, keyring tokens
and the separate read-only/terminal OAuth registrations retain their roles.
This release adds no new Google permission requirement: sending, contact writes
and mailbox changes still use the explicitly requested account capabilities.
