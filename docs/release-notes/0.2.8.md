# Omagma 0.2.8

Copying mail, sending conveniences, easier agent setup, and a browser tech demo:

- **Copy received mail into another app or agent chat.** Drag across the reader
  to select text, then press `y` or choose **Copy**. `V` opens a movable
  text cursor; reach your starting point, press `V` or Space, then extend and
  copy. Further `V` presses switch character/line selection, with explicit
  MOVE/CHAR/LINE indicators. Space unmarks for another starting point.
  Copying leaves out pane borders, padding and controls. `:copy-message`
  copies the whole focused message; `e` opens a private temporary
  text copy in your editor. Editor changes never alter received mail, and the
  snapshot is removed when you return. Clipboard writes use OSC 52, including
  over SSH when your terminal permits them.

- **Send now during the countdown.** After reviewing a message, press Ctrl+S
  or choose **Send now** to submit it immediately. Undo remains available on
  Ctrl+Z or Escape before submission. Tab/Shift+Tab moves between the buttons;
  Enter activates the focused action, with Undo initially selected. Both
  buttons are clickable and fit narrow terminals. The next message still gets
  the default ten-second delay. CLI callers can use `queue.send-now` or
  `omagma queue send-now` for the same reviewed queue entry. Repeated actions
  and uncertain outcomes retain the existing protections against duplicate
  sends.
- **Interactive or Agent-enabled Mac setup.** Onboarding asks which setup you
  want. Interactive uses the native Keychain; Agent-enabled uses private
  credential files, so agent subprocesses and SSH can use the same TUI and CLI
  without an interactive Keychain session. Existing credentials can be copied
  and verified with `omagma credentials migrate` without another Google sign-in.
  Storage selection changes only after verification, with account and grant
  identities preserved. Private files use owner-only directories and file
  permissions; the agent still needs access to Omagma's files and network.
  The bundled skill and guides also show the correct Homebrew skill location,
  stable Codex/Claude registration links, first-launch configuration and
  Keychain/SSH guidance for users choosing Interactive setup.

- **CLI help that reveals details as needed.** `omagma --help` gives a short
  overview; `omagma cli --help` shows JSONL account discovery and request/reply
  examples and the actual JSONL command catalogue. Use
  `omagma cli --help mail.read` for every public field and referenced object;
  `--schema` supplies machine-readable request schemas, and
  `omagma cli --help-all` includes the full offline reference. Documentation is
  optional for command discovery.
  Ordinary commands also have scoped help, shell examples, shared advanced
  options and bare Draft/Contact file schemas. Credential, bar and background
  commands explain their own defaults. Help works before file/stdin reads;
  usage errors point to the relevant operation.

- **Omagma comes full circle: a browser tech demo.** `omagma server` serves
  the same Zig TUI compiled to WebAssembly. Connect configured Gmail accounts,
  read mail, compose replies or forwards with preserved original formatting,
  and see the live preview. Browser drafts survive a reload; reviewed label
  changes and undo are supported. This optional demonstration is **not meant
  for everyday use** and does not replace the native TUI or agent CLI.
  [Browser instructions and limits](https://github.com/technologylab-ai/omagma/blob/v0.2.8/web-demo/README.md) describe the available
  workflows and local credential handoff.

- **More reliable everyday mail handling.** Shared header and Unicode
  handling improves compatibility in native and browser views. A malformed
  contact is isolated so healthy contacts remain usable, and incomplete
  contact data cannot silently overwrite fields. Runtime memory reservations
  and bounded decoding keep large or unusual messages from consuming an
  unbounded amount of memory. Full-cache refreshes stay within the existing
  heap cap; mail and conversation responses avoid duplicate full-body
  allocations in native and browser reads. Lowering cache limits safely trims
  older mail while protecting
  drafts and send receipts. The reader updates automatically when a previously
  unavailable body is recovered, preserving scroll and conversation focus.
  Classic terminals also recognize Ctrl+Space
  for recipient completion in the composer.

These changes require no new Google permissions. The bar remains Linux-only
and read-only; the TUI and CLI run on Linux and macOS. Follow the
[update guide](https://github.com/technologylab-ai/omagma/blob/v0.2.8/docs/UPDATES.md) for your installation, or open `:updates` in the
TUI to check for a release and see its upgrade instructions.
