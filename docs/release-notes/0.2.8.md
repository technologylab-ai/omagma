# Omagma 0.2.8

A small convenience and setup release for the experimental TUI and CLI:

- **Send now during the countdown.** After reviewing a message, press Ctrl+S
  or choose **Send now** to submit it immediately. Undo remains available on
  Ctrl+Z or Escape before submission. Tab/Shift+Tab moves between the buttons;
  Enter activates the focused action, with Undo initially selected. Both
  buttons are clickable and fit narrow terminals. The next message still gets
  the default ten-second delay. CLI callers can use `queue.send-now` or
  `omagma queue send-now` for the same reviewed queue entry. Repeated actions
  and uncertain outcomes retain the existing protections against duplicate
  sends.
- **Interactive or Agent-enabled Mac setup.** Onboarding asks which setup you
  want. Interactive uses the native Keychain; Agent-enabled uses private
  credential files, so agent subprocesses and SSH can use the same TUI and CLI
  without an interactive Keychain session. Existing credentials can be copied
  and verified with `omagma credentials migrate` without another Google sign-in.
  Storage selection changes only after verification, with account and grant
  identities preserved. Private files use owner-only directories and file
  permissions; the agent still needs access to Omagma's files and network.
  The bundled skill and guides also show the correct Homebrew skill location,
  stable Codex/Claude registration links, first-launch configuration and
  Keychain/SSH guidance for users choosing Interactive setup.

- **CLI help that reveals details as needed.** `omagma --help` gives a short
  overview; `omagma cli --help` shows JSONL account discovery and request/reply
  examples. Ask a family or operation for `--help`, or use
  `omagma cli --help mail.read` for its exact fields. The extended overview stays
  available on `--help-all`.

These changes require no new Google permissions. The bar remains Linux-only
and read-only; the TUI and CLI run on Linux and macOS. Follow the
[update guide](../UPDATES.md) for your installation, or open `:updates` in the
TUI to check for a release and see its upgrade instructions.
