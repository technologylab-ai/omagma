# Omagma 0.2.8

A small convenience and setup release for the experimental TUI and CLI:

- **Send now during the countdown.** After reviewing a message, press Ctrl+S
  or choose **Send now** to submit it immediately. Undo remains available on
  Ctrl+Z or Escape before submission. Tab/Shift+Tab moves between the buttons;
  Enter activates the focused action, with Undo initially selected. Both
  buttons are clickable and fit narrow terminals. The next message still gets
  the default ten-second delay. CLI callers can use `queue.send-now` or
  `omagma queue send-now` for the same reviewed queue entry. Repeated actions
  and uncertain outcomes retain the existing protections against duplicate
  sends.
- **Clearer macOS setup and bundled skill instructions.** The Homebrew guides
  now show the correct location of the included setup skill and how to register
  it with Codex, Claude Code or a shared skills directory. Stable Homebrew links
  follow package upgrades. The Mac guide explains account configuration before
  the first TUI launch, local Keychain approval for imported credentials, and
  unlocking the Keychain in the same SSH session when remote use reports
  `KeyringUnavailable`. Keychain approval is separate from Google consent.

These changes require no new Google permissions. The bar remains Linux-only
and read-only; the TUI and CLI run on Linux and macOS. Follow the
[update guide](../UPDATES.md) for your installation, or open `:updates` in the
TUI to check for a release and see its upgrade instructions.
