# Omagma 0.2.20

- **Outgoing HTML mail fits the reader’s window.** New messages, replies,
  reply-all messages and forwards start at the reading pane’s edge. Paragraphs
  reflow when the recipient resizes the pane.
- **Correct umlauts in received Gmail messages:** recognize inline text that
  Gmail has converted to UTF-8 while retaining its original legacy charset and
  byte count. Plain and formatted reading preserve umlauts and Windows
  punctuation without applying the legacy conversion twice. Raw MIME,
  attachments and calendar sources keep their declared encoding rules.
- **Refresh older decoded copies when opened:** retain the cached message while
  obtaining an updated body, and keep it available when the provider cannot be
  reached. Cache-only reads remain offline and current decoded bodies are reused.

The TUI and CLI remain experimental.
