# Omagma 0.2.13

Larger replies, long-lived accounts and drafts shared between clients are easier
to manage in the native Gmail and Google Calendar TUI and agent CLI.

- **Clearer compose controls.** **Preview in browser** and **Continue in Gmail**
  are visible, keyboard-accessible actions; Gmail handoff uploads without sending.
  **Q Reply without original** omits a reply's retained original and inline images
  while keeping them available to restore after restart. **z Fold / Expand**
  changes only the terminal view. Review shows MIME size and, when available,
  size without the original. Oversized drafts stay saved without automatic cuts.
- **Preserve edits across interruptions and other clients.** A changed draft
  offers explicit reload or a separate recovery copy. If another client already
  sent the source, newer edits survive under a new local ID. Copies retain Gmail
  warnings and require fresh send acknowledgement. Queued, uncertain and
  Gmail-owned drafts stay protected; recovery never resends automatically.
- **History that does not fill the active Drafts list.** Accepted sends retain
  their exact local source and receipt in paged history. Regular use no longer
  exhausts active draft slots or reaches the old lifetime receipt and file-handle
  limits. The CLI can read, clone or explicitly delete settled source content.
  Disk quotas still apply; deletion preserves the records that prevent an old
  operation from sending again.
- **Room for larger messages and accounts.** Native composition supports up to
  500 total recipients and more than 16 ordinary files, within the shared MIME
  part and byte budgets. Large label collections and more than 24 Calendar
  sources remain accessible. Draft lists load compact pages. Settled invitation
  history no longer stops after 256 identities, while prior revisions and
  cancellations remain recorded.
- **Less copying, safer encrypted streams.** Large compose redraws reuse layout,
  temporary cache snapshots release memory sooner, and encrypted metadata reads
  no longer disturb outgoing MIME. Ordinary browsing keeps fixed memory pools;
  large native compose operations use temporary memory and may exceed 256 MiB.
- **Reliable offline CLI discovery.** Help and request schemas work without
  account configuration, `HOME` or XDG paths. The complete command catalogue
  includes draft measurement and paged history. Sends can require the exact
  measured content; failures after a possible mutation preserve the uncertain
  outcome and operation identity.

**Upgrading:** close running clients and stop the vault daemon before replacing
the executable, then use the same version for all clients sharing local state.
Incompatible vault clients and daemons refuse data operations; status, lock and
stop remain available for the upgrade. Existing account indexes and Calendar invitation state are read automatically
and upgraded to schema 2 on subsequent writes. Omagma 0.2.12 and older cannot
read the upgraded state; there is no in-place downgrade. Back up the complete
cache or vault before upgrading if you need a rollback point. Do not clear it
to work around a version mismatch: it holds drafts and submission history.
The vault encryption format and password are unchanged. No additional Google
permission is required.

The **experimental** native app runs on Linux and macOS, with Mail, Contacts,
multi-calendar views, meeting and Meet creation, reminders, Follow-ups, and an
optional encrypted vault and daemon. The Omarchy bar remains read-only. The
bundled browser tech demo keeps its smaller limits and existing feature scope.
