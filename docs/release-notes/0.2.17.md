# Omagma 0.2.17

Add booking confirmations to your calendar directly from Mail.

- Add attendee-free booking confirmations to Calendar through the native mail
  notice's **A Calendar** action. Use one compact themed confirmation,
  then **Add appointment**; technical identifiers live under **Details**.
  The appointment has no guests and sends no reply.
- Mail → Calendar defaults to the receiving account's primary calendar and
  shows that destination in the review. No mandatory calendar picker.
- Attendee-free bookings become personal appointments on the verified primary
  calendar, with the original organizer retained as provenance and no guests.
  Provider rejection details are shown instead of only a generic error code.
- Preserve original UID duplicate detection, times and embedded time-zone checks.
  RSVP still requires a verified matching attendee.

No additional permission is needed if Calendar writing is already authorized
for the selected account and calendar. Restart open clients after updating.

The **experimental** native app supports Linux and macOS; the bar remains
read-only and the browser remains a tech demo.
