# Omagma 0.2.10

Create and reschedule meetings from the terminal, combine your calendars, and
find the event you need in a busy week.

- **Create, edit and move meetings in the TUI.** Press `n` for a new event or
  `e` to edit a normal organizer-owned event, including a selected recurring
  occurrence. Choose the account and writable calendar explicitly, then review
  before confirming. Rescheduling preserves the event's identity, existing
  guests, responses and conference. Concurrent changes require a fresh review.
  Use Google Calendar for whole recurring series and attendee copies.

- **All-day events and clear local times.** Enter an all-day event's last
  included date; Omagma handles Google's exclusive end date. Timed events use
  an explicit time zone. Repeated daylight-saving times offer a first/second
  occurrence choice; skipped times must be corrected.

- **Invite guests and add a meeting link.** Generate Google Meet details on
  supported calendars, or paste an existing HTTPS meeting link. Review the
  guests and notification choice before saving; adding guests sends invitations
  and notifies all participants after confirmation. Existing HTML notes and
  guest responses stay intact.

- **Choose guests from Contacts.** The guest picker uses the destination
  account's address book and lets you choose each email address. Adding a guest
  preserves existing entries and avoids duplicates. Manual email entry remains
  available without Contacts permission.

- **Remember the calendars you want to see.** Combine sources from one or all
  configured accounts, including read-only subscriptions such as holidays.
  Checkbox visibility and theme colours persist across restarts, with source
  letters and account labels available without colour. Mark one exact source
  as **Priority** to help order events in Week.

- **Find events in a crowded week.** Taller views show up to four distinct
  titles per hour. Click `+N` to list that exact hour's events, or press `Space`
  for **Show all** across the selected event's visible hour rows. Choose using
  full dates, time zones, calendar and account names. All-day events have their
  own chooser. Revealing a long event keeps that choice in one hour, leaving new
  starts visible in other hours.

- **Recover an uncertain save after restarting.** Saved reviews let you check
  whether Calendar accepted a request without sending invitations again.
  Retrying the identical request or archiving its uncertainty each requires
  separate confirmation. The native CLI exposes the same review, apply and
  recovery workflow.

- **Open Calendar in the owning account's browser profile.** `O` opens Google
  Calendar and `b` opens the selected event in that account's configured Chrome
  profile. `o` continues to join the meeting directly.

- **Smoother Mail navigation and formatting.** Sidebar keyboard, mouse and
  scrolling now follow the same Contacts, Calendar, Follow-ups and Labels order;
  Tab/Shift+Tab retain the chosen destination. Formatted previews preserve
  inline-code whitespace styling and keep link-edge gaps undecorated.

Calendar remains optional per account. Existing `calendar-write-owned` or
`calendar-write-shared` grants cover the editor and generated Meet links; no
additional Meet scope is needed. Reading other subscribed calendars may require
`calendar-read`. See [Calendar permissions](https://github.com/technologylab-ai/omagma/blob/v0.2.10/docs/CALENDAR-PERMISSIONS.md)
and the [event guide](https://github.com/technologylab-ai/omagma/blob/v0.2.10/docs/CALENDAR-EVENTS.md).

Use one Omagma version per private store: 0.2.9 cannot read the new event journal
or customized Calendar visibility/colour preferences. Existing 0.2.9 invitation
and RSVP reviews remain supported when upgrading.

The **experimental** native TUI and CLI run on Linux and macOS, retaining Mail,
meeting reminders, Follow-ups and optional encrypted-vault storage. The bar
remains read-only. The browser tech demo remains available; Calendar and vault
parity in the browser are deferred.
