# Omagma 0.2.5

Three improvements make the experimental TUI easier to leave open and return to:

- **Live cached mail updates.** The TUI adopts mail written by the background
  refresh or another Omagma client without Ctrl+R. New rows appear while your
  selected message and reader position stay in place. A compact **New mail**
  card accumulates arrivals separately for each account and clears on your next
  interaction. It stays out of composing, contacts, search and expanded reading.
- **`gg` across the cache.** Jump to the first message in the entire cached
  mailbox or result set, even from a later window, with either the list or reader
  focused. Expanded reading keeps `gg` as scroll-to-top for the current body.
- **Cleaner mail rendering.** HTML-only mail handles malformed marketing
  markup, hidden styles and Office layout debris more cleanly. Links are cyan
  and underlined in HTML and plaintext; long visible URLs show a compact
  host/path while `L` keeps the complete destination. Images show a caption or
  `[Image]`, with decorative empty-alt images omitted. No remote resources load.
  Genuine plaintext alternatives and literal technical angle brackets remain
  intact; stored bodies and CLI output are unchanged by these display rules.

The full feature set remains available: the read-only three-account Omarchy bar;
cache-first terminal reading and continuous mail-window navigation; formatted
HTML-only messages and folded threads; local drafts, compose, reply/reply-all
and forwarding; `$EDITOR`, multiple attachments and explicit send review;
cached-correspondent completion, contacts and sender identities/signatures;
bulk actions with undo, existing-label views, invitation replies, local dates
and saved working context. The agent CLI provides one-shot commands and bounded
account-scoped JSONL operations, with cache-only and explicit server search.

The TUI and CLI remain **experimental** on Linux and macOS. The Omarchy bar is
Linux-only. Existing account configuration and Google OAuth registrations keep
their roles: the bar remains read-only, broader terminal permissions use the
requested per-account grant, and sending or mailbox/contact changes require
an explicit action. This release adds no new Google permission requirement.
