# Omagma 0.2.16

More useful link choices in the native mail reader.

- **Recognize links by their visible text.** Press `L` in the reader to see
  descriptive link titles above indented destination URLs. Titles use the
  sender colour; bare URLs stay on one line. Styled text and HTML entities
  remain readable, and repeated destinations appear once.
- **Keep the original destination.** Enter opens the complete original URL
  in the selected account's configured browser profile, even when a long row
  is shortened on screen. Titles come from the email itself; no page fetch
  or tracking-link unwrapping is needed.
- **Navigate whole entries.** Keyboard navigation and mouse selection work
  across title and destination rows. Narrow terminals and no-colour mode
  retain the same structure; very short terminals show the destination only.

No new Google permission or account setup is needed. Existing accounts,
drafts and settings are preserved. Restart open clients after updating.

The **experimental** native app runs on Linux and macOS. The Omarchy bar
remains read-only; the browser version remains a tech demo with its existing
scope.

See [terminal usage](https://github.com/technologylab-ai/omagma/blob/v0.2.16/docs/TERMINAL.md)
and the [agent CLI guide](https://github.com/technologylab-ai/omagma/blob/v0.2.16/docs/AGENT-CLI.md).
