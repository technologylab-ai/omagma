# Omagma 0.2.7

Original formatting and everyday polish for the experimental TUI and CLI:

- **Keep formatting in replies and forwards.** Write your own Markdown or
  plain-text note above the original HTML, retaining its layout, tables,
  styling and embedded images. The note keeps Omagma's branded design; the
  original stays read-only through editing, previews and draft recovery.
  Text quotes remain available, and forwarding also offers an original `.eml`
  attachment. CLI replies and forwards support `--preserve-formatting`.
- **Better compatibility with imperfect email HTML.** Preserve original
  document mode, attributes, styles and trailing content without rebuilding
  its markup. A 39-case synthetic Chromium comparison covers recoverable
  source patterns and explicit refusals when no safe insertion point exists.
- **Manage custom labels in both interfaces.** Create, rename and delete
  account labels in the TUI or CLI. Collection management is separate from
  adding/removing labels on a message; deleting a label keeps the mail.
- **Searchable Help and complete keyboard controls.** Search Help with `/`
  and navigate matches with `n`/`N`. Reach dialog buttons with Tab/Shift+Tab
  and Enter, with clearer contextual shortcuts for labels, files, contacts,
  aliases and composition. Ctrl+U/D scroll half a visible mail-list page.
- **Themes and clearer message status.** Preview and save the orange Omagma
  theme or Follow Omarchy. Read/unread styling, stars and label names are
  visible; text padding, stale display artifacts and link underline spacing
  are improved.
- **Invitation responses that stand out.** A distinct response callout sits
  below message labels with breathing room and stays visible when scrolling.
  The existing Accept, Tentative and Decline review flow remains explicit.
- **Easier launching and safer composition.** Open the selected account's TUI
  from the bar or application launcher. Setup documents the optional Omarchy
  email shortcut and a generic launcher for other Linux desktops. Missing
  recipients keep the draft editable instead of starting a submission.

Markdown mail, multiple attachments, native file browsing, live cache updates,
per-account new-mail cards and the existing mail/contact workflows remain
available. The TUI and CLI are **experimental** on Linux and macOS; the Omarchy
bar remains Linux-only and read-only. This release adds no new Google permission
requirement. Existing account grants and separate bar/terminal registrations
retain their roles. New measurements are not implied by this version bump;
published memory observations retain their original versions and workloads.
