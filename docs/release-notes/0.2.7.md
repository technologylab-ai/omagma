# Omagma 0.2.7

Original formatting, friendly meetings and a smoother daily workflow for the
experimental TUI and CLI:

- **Keep formatting in replies and forwards.** Write your own Markdown or
  plain-text note above the original HTML, retaining its layout, tables,
  styling and embedded images. The note keeps Omagma's branded design; the
  original stays read-only through editing, previews and draft recovery.
  Text quotes remain available, and forwarding also offers an original `.eml`
  attachment. A private browser preview shows the outgoing HTML with its
  styles and verified inline images. CLI replies and forwards support
  `--preserve-formatting`.
- **Better compatibility with imperfect email HTML.** Preserve original
  document mode, attributes, styles and trailing content without rebuilding
  its markup. A 39-case synthetic Chromium comparison covers recoverable
  source patterns and explicit refusals when no safe insertion point exists.
- **Styled calendar invitation cards.** A tinted card with an orange edge,
  calendar icon and clear response cue sits below message labels, separated
  by a blank line when space permits. It pins to the top as you scroll a long
  email and adapts to short panes and monochrome terminals. Click it or press
  `I` to review; the Accept/Tentative/Decline/Cancel controls support Tab/Enter
  and initially focus Cancel. Friendly local times, duration, location and
  response details replace raw scheduling fields; `o` in this review joins
  the online meeting explicitly.
- **A separate label manager in both interfaces.** Click the sidebar's LABELS
  heading or use `:labels` to create, rename, delete or open an account's
  custom labels. The CLI shares collection management. The message assignment
  picker hides system labels and shows checked, mixed or absent membership.
  Stage several changes, keep them while filtering, then Apply once or Cancel.
  Custom labels also have a color picker with readable text. Saving a reviewed
  color interrupts background reads; if another write is active, the picker
  keeps your choice for retry. Deleting a label keeps the mail; return to Inbox
  to leave a label's message view.
- **Searchable actions and Help.** Ctrl+P in the mailbox opens a contextual
  action palette; `:actions` discovers commands in other supported views.
  Search shortcuts, descriptions and section names in Help with
  `/`, with live highlighting and `n`/`N` navigation. Escape clears the search
  before leaving Help. Contextual hints now expose more editor, file, preview,
  label and theme actions, including in narrow dialogs.
- **Find and reuse searches.** Find displayed message text with `:find` and
  `n`/`N`, with a persistent match counter. Jump to the next or previous unread
  cached mail without marking it read. Cache search adds filename, date and
  important-state predicates; bounded history and named searches preserve
  account and Cache/Gmail scope across restart.
- **Compose with names and native undo.** Recipient suggestions and contact
  choices retain `Name <address>` in To/Cc/Bcc. Ctrl+Z/Ctrl+Y restores text and
  caret positions, with paste and editor return grouped into single steps;
  an explicit verified From chooser replaces blind cycling.
  Send review warns when the authored note promises a missing attachment.
- **Files together, including larger ones.** Select several files across
  folders and attach the complete set. Save All/selected preserves existing
  files with fresh names, stops on a failure and reports what was saved for
  explicit retry. Immutable account
  storage and bounded streaming support larger ordinary attachments, with a
  25 MiB combined decoded limit and explicit MIME/disk quotas.
- **A moment to change your mind.** Confirming send starts a cancellable
  ten-second countdown; Undo returns to the retained draft before submission.
  `:send-grace 0..30` changes the period. Interrupted queued sends stay paused
  after restart, with explicit Resume/Cancel for the matching draft and account.
  The CLI shares queue controls and delayed-send support.
- **Clear message or conversation scope.** Resolve complete conversation IDs
  before reviewed actions and show the account, subject and count. Stable
  triage position, focused-message toggles and selective undo keep unrelated
  state intact; delayed results cannot retarget a different selection.
- **More complete daily workflows.** Contacts preserve their supported
  addresses and provider metadata; choose an address or prefill a contact from
  the sender. Local draft discard starts on safe Cancel. Spam/Not spam and
  shared CLI operations complete the mailbox workflow.
- **Keyboard controls throughout dialogs.** Tab/Shift+Tab and Enter reach
  label actions, links, attachment Save/Save & open, contact Save/Cancel,
  sender aliases, and send/Trash/invitation reviews. Reviews start on Back or
  Cancel; submitting requires deliberately choosing the action.
- **Theme picker with live preview.** Preview and save the orange Omagma
  theme or Follow Omarchy. Cancel restores the saved palette; Follow Omarchy
  adopts desktop theme changes automatically and falls back to Omagma when
  no palette is available.
- **Clearer message status.** Unread subjects are bold with a dot; read
  subjects use normal weight. Stars remain visible independently of bulk
  selection, known attachments show a paperclip beside the subject, and reader
  headers display readable message label names.
- **Smoother navigation and rendering.** Ctrl+U/D scroll half a visible
  mail-list page; PageUp/PageDown scroll a full page. Invisible padding and
  stale display artifacts are corrected, and link underlines stay off
  surrounding spaces and punctuation.
- **Launch the TUI from the desktop.** The bar's Open TUI button opens its
  selected account in a centered floating terminal. Setup includes the app
  launcher entry, an optional Omarchy Super+Shift+E email shortcut, and a
  generic launcher for other Linux desktops.
- **Missing-recipient checks.** Trying to review a send without recipients
  returns focus to To and keeps the draft editable, without creating an
  uncertain submission.
- **Upgrade notices with the right instructions.** A daily background check
  shows a keyboard-accessible Upgrade available card on the main mailbox
  screen. Dismiss remembers a release; How to update identifies the running
  installation and offers commands, release notes and an agent handoff.
  Omarchy Git plugins, release bundles, Homebrew and manual installations get
  their own procedures. The saved interval survives restart, automatic checks
  can be disabled, and the CLI shares status/check/guide/dismiss controls.
  Public release checks need no Google authorization.

Markdown mail, multiple attachments, native file browsing, live cache updates,
per-account new-mail cards and the existing mail/contact workflows remain
available. The TUI and CLI are **experimental** on Linux and macOS; the Omarchy
bar remains Linux-only and read-only. This release adds no new Google permission
requirement. Existing account grants and separate bar/terminal registrations
retain their roles. New measurements are not implied by this version bump;
published memory observations retain their original versions and workloads.
